# Roadmap

This file tracks potential improvements for this repo (quality, maintainability, and “next steps”).

## Repo-level

- Add a consistent tooling story across apps (formatting + linting).
- Add CI checks on pull requests (lint + build).
- Consider consolidating common configs (where it reduces duplication).

## App-level

- TypeScript migration (start with one app as the template).
- Add tests where they provide real value (Vitest + React Testing Library).
- Improve environment variable documentation per app (keep required keys close to the app).

## Product ideas

- Add another small API-based project (e.g., weather dashboard) to round out the portfolio.
